# Docker ARM镜像构建与跨平台部署方案

## 1. 概述

本方案旨在为ARM架构构建Docker镜像，并将这些镜像及对应的数据卷完整迁移至内网的麒麟ARM64操作系统进行部署。所有操作严格限定在`docker-arm`文件夹内执行。

## 2. 系统架构

系统包含以下核心服务：
- PostgreSQL数据库服务（pgDB）
- MinIO对象存储服务
- Redis缓存服务
- RabbitMQ消息队列服务
- Elasticsearch搜索引擎服务
- OnlyOffice文档服务
- GeoServer地图服务
- AICCG Boot后端服务
- AICCG Vue前端服务

所有服务将加入同一个名为`aiccg-networks`的自定义桥接网络，确保容器间可通过服务名相互访问。

## 3. 构建流程

### 3.1 环境准备
1. 在Windows 10 x64环境下安装Docker Desktop
2. 启用Docker Buildx功能以支持多平台构建
3. 配置Docker Hub或其他镜像仓库访问权限

### 3.2 ARM镜像构建步骤
1. 为每个服务创建独立的构建环境
2. 使用Docker Buildx构建ARM64架构镜像
3. 将构建好的镜像推送到镜像仓库或导出为tar文件

### 3.3 构建命令示例
```bash
# 创建新的builder实例
docker buildx create --name mybuilder --use

# 构建并推送到镜像仓库
docker buildx build --platform linux/arm64 -t username/imagename:tag --push .

# 或者导出为tar文件
docker buildx build --platform linux/arm64 -t username/imagename:tag -o type=docker,dest=imagename.tar .
```

## 4. 迁移步骤

### 4.1 镜像迁移
1. 将构建好的镜像tar文件通过安全介质拷贝到麒麟ARM64系统
2. 在麒麟系统上导入镜像：
```bash
docker load -i imagename.tar
```

### 4.2 数据卷迁移
1. 在Windows系统上导出数据卷：
```bash
docker run --rm -v volumename:/volume -v /tmp:/backup busybox tar czf /backup/volumename.tar.gz -C /volume ./
```
2. 将数据卷文件拷贝到麒麟系统
3. 在麒麟系统上导入数据卷：
```bash
docker volume create volumename
docker run --rm -v volumename:/volume -v /tmp:/backup busybox tar xzf /backup/volumename.tar.gz -C /volume
```

## 5. 部署指南

### 5.1 环境准备（麒麟ARM64系统）
1. 安装Docker Engine
2. 配置Docker网络和存储
3. 创建必要的目录结构

### 5.2 服务部署步骤
1. 导入所有服务镜像
2. 恢复数据卷
3. 配置环境变量
4. 启动服务（按照依赖关系顺序）

### 5.3 启动顺序
1. pgDB (PostgreSQL)
2. aiccg-boot-redis
3. rabbitmq
4. elasticsearch
5. aiccg-boot-minio
6. onlyoffice
7. geoserver
8. aiccg-boot-system
9. aiccg-vue

### 5.4 服务验证
1. 检查各服务容器状态
2. 验证服务间网络连通性
3. 测试关键功能接口

## 6. 维护与监控

### 6.1 日常维护
1. 定期备份数据卷
2. 监控容器资源使用情况
3. 更新安全补丁

### 6.2 故障处理
1. 查看容器日志：`docker logs container_name`
2. 进入容器调试：`docker exec -it container_name /bin/bash`
3. 重启服务：`docker-compose restart service_name`

## 7. 安全建议

1. 使用安全的密码策略
2. 定期更新镜像版本
3. 限制容器权限
4. 启用Docker内容信任
