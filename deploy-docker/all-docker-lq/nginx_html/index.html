服务访问中心

以下是Docker环境中运行的所有服务的访问信息

OnlyOffice 文档服务

描述：支持中文环境和字体的在线文档编辑服务

端口：9000

功能：在线编辑文档、表格、演示文稿

直接访问 通过Nginx访问

PostgreSQL 数据库

描述：集成PostGIS和pgvector扩展的PostgreSQL 18

端口：5432

功能：地理空间数据存储、向量搜索

请使用数据库客户端连接

MinIO 对象存储

描述：高性能的对象存储服务

API端口：9001

控制台端口：9002

直接访问控制台 通过Nginx访问控制台

Elasticsearch 搜索引擎

描述：分布式全文搜索引擎

端口：9200

功能：全文搜索、日志分析、数据可视化

直接访问API 通过Nginx访问API

Redis 缓存服务

描述：高性能键值存储数据库

端口：6379

功能：缓存、会话存储、消息队列

请使用Redis客户端连接

RabbitMQ 消息队列

描述：可靠的消息代理和队列服务器

AMQP端口：5672

管理界面端口：15672

直接访问管理界面 通过Nginx访问管理界面

Nginx 反向代理

描述：高性能Web服务器和反向代理

HTTP端口：80

HTTPS端口：443 (未配置)
